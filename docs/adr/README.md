# Architecture decision records

Каждый файл здесь фиксирует одно решение: что выбрали, почему, что рассмотрели
и отвергли, и по какому измерению. Это не описание кода — код описан в
`docs/systems`-документах каталога выше. Здесь хранится причина, чтобы её не
пришлось выводить заново и чтобы решение не «улучшили» обратно.
