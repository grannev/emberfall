Этот каталог описывает текущее устройство игрового прототипа, его публичные C
API, правила симуляции и порядок проверки изменений.

## Быстрый старт

```sh
make
make run
```

Управление:

- `WASD` — свободный полёт;
- `Shift` вместе с `WASD` — три ступени ускорения с бурением; долгое прямое
  ускорение заканчивается сверхзвуковым полётом;
- мышь — прицел;
- ЛКМ — контактный лазер;
- ПКМ — взрыв;
- `Q` — мощный силовой удар, далеко отбрасывает подвижную материю;
- `E` — криолуч, замораживает воду и осаживает лаву;
- `R` — новая карта и полный сброс игрового состояния;
- `F1` — debug HUD;
- `Esc` — выход.

Короткие автоматические проверки:

```sh
make test
make bench
make run RUN_ARGS=--smoke-test
```

`make test` — headless-набор по ядру симуляции, ему не нужны ни окно, ни звук.

Документация ориентирована на разработчиков. Краткая инструкция игрока и
установка зависимостей находятся в корневом [README](../README.md).
