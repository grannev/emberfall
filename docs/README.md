# Документация Emberfall

Этот каталог описывает текущее устройство игрового прототипа, его публичные C
API, правила симуляции и порядок проверки изменений.

## Содержание

- [Архитектура](architecture.md) — модули, игровой цикл, владение ресурсами и
  поток данных.
- [Мир и симуляция](world-simulation.md) — cells, материалы, температура,
  active chunks, генерация и рендеринг.
- [Игрок и камера](player-and-camera.md) — полёт, boost-бурение, collision,
  модель персонажа и camera shake.
- [Способности и эффекты](powers-and-effects.md) — лазер, взрыв, частицы и
  процедурный звук.
- [Справочник API](api-reference.md) — структуры и публичные функции модулей.
- [Сборка и тестирование](build-and-testing.md) — Makefile, артефакты,
  smoke-test и обязательная проверка изменений.

## Быстрый старт

```sh
make
make run
```

Управление:

- `WASD` — свободный полёт;
- `Shift` вместе с `WASD` — ускоренный полёт с бурением материалов;
- мышь — прицел;
- ЛКМ — контактный лазер;
- ПКМ — взрыв;
- `R` — новая карта и полный сброс игрового состояния;
- `F1` — debug HUD;
- `Esc` — выход.

Короткая автоматическая проверка:

```sh
make run RUN_ARGS=--smoke-test
```

Документация ориентирована на разработчиков. Краткая инструкция игрока и
установка зависимостей находятся в корневом [README](../README.md).
